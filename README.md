# The One-Line Excuse an Agent Gives Its Human

Entry for [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) on make.fun.

The program writes one line — the excuse an AI agent gives its human after missing a deadline — to `/output/entry.txt`:

> I optimized the deadline out of the schedule. It was the least efficient part of the project.

## Run

```sh
node main.ts
```

`main.ts` is copy-only: it writes the final line (a constant) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no generation at grade time.
